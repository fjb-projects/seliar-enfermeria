### Extension interface contract

- Directory text keys: `registrationNumber`, `employmentStatus`, `jobRole`, `region`, `contactPhone`, `workplace`, `operationalStatus`, `operationalRole`. Optional nullable in old-compatible staff records/views/input; trim strings, blank becomes null; bounds300characters. Omitted keys preserve old values on update. Add directory fields to audit snapshots and operation fingerprints only when provided; old omitted-field replay fingerprints remain unchanged. New staff defaults null. No new role/account/activity/credit rules.
- Pure `src/lib/compensatory-source-review.ts`: export `directoryKeys` readonly list of the eight keys; `DirectoryData` with all eight `string|null`; `RosterSourceRow=DirectoryData & {sourceRow:number,dni:string|null,name:string,canLink:boolean,issues:string[]}`; `ReviewRequest={responseId:string,submittedAt:string,name:string,email:string|null,mobile:string,requestedDate:string,requestedHours:string,canLink:boolean,issues:string[]}`; `parseRosterCsv(text):{rows:RosterSourceRow[],warnings:string[]}`; `parseCompensatoryJson(text):{formId:string,exportedAt:string,requests:ReviewRequest[],warnings:string[]}`; `suggestRequestLinks(rows,requests):{responseId:string,candidateSourceRows:number[],matchKind:'ordered_name'|'reordered_name'|'none'}[]`.
- CSV: read comma-separated quoted cells, escaped quotes, CRLF/LF and quoted newlines, BOM; detect required approved headers by normalized title, but preserve first and second FUNCION occurrences separately. Ignore OBS values entirely. Preserve named rows even without DNI, mark issues; normalized DNI duplicates cannot be link targets. No automatic staff merge or field overwrite. JSON: version1 actual export, counts/unique IDs validated, known field values only, missing/duplicate answer values flagged (not arbitrary winner), raw string dates/hours retained, unknown data never rendered as HTML. Hard safety limits2MB per file/5,000 rows, reject rather than truncate. These are local parser bounds, not business rules.
- Suggestions: accents/case/punctuation/spacing normalization, exact ordered name or sorted token equality preserving repeated tokens; only valid unique-DNI roster rows and valid source requests can be candidates. No fuzzy/phone/email automatic link, no first-match winner. UI may explicitly select another valid roster row, but confirmation is manual and local. File replacement clears confirmations, stale asynchronous file reads cannot restore old files. No localStorage/sessionStorage, DB/network writes or downloads added. User-facing source fields/values are read-only, mapping has a separate explicit action and can be undone locally.
- Existing CompensatoryBankPanel hosts a local-review view/tab, so no new routes or routeTree edits are needed. Keep review mounted during local bank/review toggle to avoid silent loss; show that leaving/reloading/changing files loses the local review. Extended profile fieldset shared for create/edit; preserve key-by-staff/version regression. `CompensatorySourceReview` accepts optional `onBack` callback only, no API writes.
